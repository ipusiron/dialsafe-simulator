**Day050 - 生成AIで作るセキュリティツール100**

DialSafe Simulatorは、ダイヤル式金庫の正規の開け方と内部の動きを、ブラウザー上で学べる可視化ツールです。日本の家庭用耐火金庫に多い「4枚座の固定ダイヤル錠」を、ツク（突起）同士の遊びの連鎖として模型にしています。ダイヤルを回すと、ドライビングディスクのツクがほぼ1回転してから次のディスクを拾い、ゲートが動く様子がそのまま見えます。開くかどうかはゲートの位置だけで決まるので、「右に4回・左に3回・右に2回・左に1回」で開く理由と、回し過ぎると開かない理由が、模型の動きから分かります。

本ツールは2つのタブで構成しています。

1. 学習（Learn）: 固定ダイヤル錠の構造・開錠の仕組み・操作法と、手順の回数の意味を解説する
2. シミュレーター（Simulator）: 実機と同じ向きのダイヤルを回して開ける。手順ガイド・内部の動き・自動実演つき

> 本ツールは教育（正規操作の理解）を目的とし、攻撃・バイパス手法は扱いません。

## 🔐 対象とするダイヤル錠

金庫のダイヤル錠には多様な方式があります。本ツールは、日本で広く普及する家庭用の「4枚座の固定ダイヤル錠（固定変換ダイヤル錠）」を簡易モデル化して可視化しています。

![固定ダイヤル錠の外観](assets/DialLock.jpg)

実機仕様・メーカー差によって構造や操作手順は異なる場合があります。本ツールは教育用の簡略化モデルです。

- 対象: 4枚座の固定ダイヤル錠（固定変換ダイヤル錠）
- 想定: 目盛「0–99」、4番号の正規解錠、国産機で一般的な「最初は右回し」手順
- 非対象: 可変変換型／別規格・商用大型金庫の特殊機構／電子錠など

> 研究・教育以外の目的（不正アクセス・器物損壊等）での利用を禁止します。

## ✨ 機能

### 📚 学習タブ

- 固定ダイヤル錠とは、構造（主要部品）、開錠メカニズム（図1〜3）、操作法（4つの手順と回数の数え方）
- 右・左の向き: 右は時計回り。目盛りは時計回りに増えるので、右に回すと指標の下の数字は小さくなる（実機の写真つき）
- なぜこの回数なのか: ディスクが動き出すまでの目盛り数を模型の値で示し、各手順で何枚のディスクを動かすかを説明する

### 🎛️ シミュレーター

- 目盛りつきのダイヤル（0〜99、時計回りに増える）。右（時計回り）に回すと数字が減る。指標の数字は回らない枠に大きく出す
- 回し方: ダイヤルのドラッグ、「右へ」「左へ」ボタン（押し続けると連続で回る）、ダイヤルを選んでから←→キー（Shiftで10目盛り）
- 手順ガイド: 番号カードの4つの手順のどこにいるか、番号が指標に来た回数、回し過ぎ・向きを変える所の誤り・左から始めたことを知らせる
- 鍵を回す: 4つのゲートがフェンスの位置に揃っていれば開く。開かなければ、ずれているディスクとずれ（目盛り）を出す
- 内部の動き: 各ディスクのゲートと2種類のツク（押される側・押す側）を横の帯で描く。ツクが当たっているディスクと、揃ったゲートを色で示す

### 🎬 自動実演

- 初期状態（左に回して止めた状態）から、模型を実際に1目盛りずつ回す5つの実演
- ①正確な操作、②右に5回（多め）、③右に3回（不足）、④最後に左へ2回（回し過ぎ）、⑤STEP2で番号違い
- 各手順で回した目盛り数、鍵を回した結果、開かなかった理由を記録に出す。速さ（ゆっくり・ふつう・速い）を選べ、途中で止められる

### 🌐 画面

- 日本語・英語の切り替え（`?lang=ja`・`?lang=en`、選択は保存）、ライト・ダークの切り替え（OSの設定にも従う）
- 幅390pxのスマートフォンでも横にはみ出さない。ボタンは高さ44px以上
- タブは矢印キー・Home・Endでも移れる。手順ガイドと結果は読み上げにも伝わる（aria-live）
- index.htmlをファイルとして直接開いても動く（通常のスクリプトで作っている）

## 📖 使い方

1. シミュレーターのタブを開く。初期状態は、左に回して止めた状態（3枚のディスクとも、左回しの側でツクが当たっている）
2. 番号カードを見ながら、右に回して94を4回目で止める（94が指標の前を3回通り過ぎ、4回目でちょうど止める）
3. 向きを変え、左に回して30を3回目で止める。続けて右に回して84を2回目、左に回して13を1回目で止める
4. 「鍵を回す」を押す。4つのゲートが揃っていれば開く。開かなければ、ずれているディスクが表示されるので、リセットしてやり直す
5. 内部の動きで、ツクが当たってディスクが一緒に回り始める瞬間を見る
6. 自動実演で、回数を変えたときや番号を間違えたときに開かない理由を見る

## 🔩 固定ダイヤル錠の基礎（4枚座・固定変換）

以下は[『ハッカーの学校 鍵開けの教科書』](https://akademeia.info/?page_id=299) P451よりの抜粋・要約です。

### 耐火金庫の固定ダイヤル錠の基本構造

主要部品と特徴は次のとおりです。

- 目盛盤（つまみ）：0-99の目盛りが印字された操作部。直径が大きいほど高級品
- 表座（指標つき台座）：赤い指標または切り込み線付きの台座
- 第1〜第3ディスク：各ディスクにゲート1個とツク2個を配置
- ドライビングディスク（駆動座）：他より大きく、ツク1個、目盛盤と芯棒で直結
- 芯棒：パイプ内を通る中心軸、ドライビングディスクのみと接続
- テンションスプリング：各ディスクを密着させ、ツク同士の接触を保つ
- L寸法：表座からドライビングディスクまでの距離、扉厚より大きく必要

![断面概略（要素名称）](assets/AntiFire_DialLock_Component.png)

芯棒を介してドライビングディスクのみが目盛盤と直結し、まずドライブされます。他ディスクはテンションスプリングで密着しており、各ディスクのツク（突起）同士が当たりながら順次回転を伝達します。

バネが弱くなるとツクが空回りして故障の原因となります。故障診断：目盛盤を回しても負荷が変わらない場合はバネ故障。応急処置として金庫を寝かせると重力でディスクが密着します。

![横から見ると4枚のディスクの存在がわかる](assets/DialLock1.jpg)
![裏から見たところ](assets/DialLock2.jpg)
![写真手前（ダイヤルから一番奥）がドライビングディスク](assets/DialLock3.jpg)

### 固定ダイヤル錠機構と鍵機構の関連性

固定ダイヤル錠と鍵の錠前の連動部を上から見ると、次のようになります。

![固定ダイヤル錠と鍵の錠前の連動](assets/dial_lock.png)

### ダイヤル錠の施解錠の状態

ダイヤル錠は内部に複数のディスク（円板）を持ちます。4枚のディスクなら、解錠には4つの数字を用います。

まず理解のために1枚の円板だけを考えます。

円板には1つの切り欠き（ゲート）があり、鍵側が施錠のままなら閂は出たままで扉は開きません（図1）。

![図1：鍵側が施錠で閂が出ている（扉は開かない）](assets/DialLock_Lock1.png)

鍵側を解錠しても、ダイヤル側のゲートが解錠位置でなければ閂を完全に引き込めず、扉は開きません（図2）。

![図2：鍵側のみ解錠だが、ダイヤル側ゲートが合わず閂を引き込めない](assets/DialLock_Lock2.png)

鍵側が解錠かつダイヤル側のゲートが解錠位置にあると、閂を完全に引き込めるため扉が開きます（図3）。

![図3：鍵側解錠かつダイヤル側ゲート位置が合致 → 閂を引き込み開扉](assets/DialLock_Lock3.png)

4枚ディスクでも同様で、4つのゲートが閂側に一直線に揃い、加えて鍵側が解錠されてはじめて扉が開きます。

### ダイヤル錠の正規の解錠法（4枚座・国産固定ダイヤル）

![固定変換ダイヤル錠のダイヤル目盛り](assets/DialLock5.jpg)

ダイヤル合わせで4番号を順に入力します。ここでの「○回まわす」は、解錠の数値が指標を○回通過する意味です（「0」ではありません）。**回し過ぎたらやり直し**です。

1. 右に4回以上まわしてから、1番目の数値で停止
2. 左に3回まわして、2番目の数値で停止
3. 右に2回まわして、3番目の数値で停止
4. 左に1回まわして、4番目の数値で停止

- ①完了で第1ディスクのゲートが解錠位置
- ②完了で第2ディスク
- ③完了で第3ディスク
- ④完了でドライビングディスク
- → 4枚すべてのゲートが揃う状態になる

> 構造上、左始動でも最終的にゲートを揃えることは可能ですが、番号列は右始動前提で設計されています（ツク厚み分の誤差が出るため）。**国産は右始動が一般的**、欧米は左始動が多い点にも注意。

最後に鍵を挿入して時計回りに回転し、解錠します。鍵の解錠位置のまま引くことで扉を開けます（鍵がつまみの役割）。

## 🔬 模型の仕組みと検算

本ツールは、ディスクの動きを「ツクの遊び」の連鎖として計算します（`js/dial-core.js`）。

- 単位は目盛り（1周＝100）。右（時計回り）に1目盛り回すと指標の数字が1減り、左に回すと1増える
- ドライビングディスクは芯棒で直結し、ダイヤルと同じだけ回る
- 第3・第2・第1ディスクは、駆動側のディスクとの角度の差が0〜96目盛りの範囲で遊ぶ。範囲を出ると、ツクに押されて一緒に回る（96＝100−ツクの厚み4）
- フェンスは、4つのゲートがすべてフェンスの位置から±1目盛り以内に揃ったときに落ちる
- 正解番号94-30-84-13から、各ディスクのゲートの位置を逆算している（右で押して止める第1・第3ディスクは番号どおり、左で押して止める第2ディスクは遊び2つ分ずれる）

左に回して止めた状態から右へ回すと、第3・第2・第1ディスクは97・193・289目盛りで動き出します。右4回目で止めれば必ず289目盛りを超えるので、どの状態から始めても3枚を拾い切れます。左3回目では第2ディスクまで、右2回目では第3ディスクまでしか動かさず、先に合わせたディスクには触れません。

ランダムな初期状態2,000通り（決まった種）で、手順ごとに鍵を回して開いた割合です。

| 操作 | 開いた割合 |
|---|---|
| 正規の手順（右4・左3・右2・左1） | 100.0% |
| 最初に右5回 | 100.0% |
| 最初に右3回 | 97.0% |
| STEP2で左4回（回し過ぎ） | 0.0% |
| STEP3で右3回（回し過ぎ） | 0.0% |
| STEP4で左2回（回し過ぎ） | 0.0% |
| STEP2の番号を1目盛りずらす | 100.0% |
| STEP2の番号を2目盛りずらす | 0.0% |
| 左始動（左4・右3・左2・右1）、同じ番号 | 0.0% |
| 左始動、ツクの厚みのぶんずらした番号（82-38-80-13） | 100.0% |

- 最初に右3回で開かなかった3.0%は、第1ディスクを拾い切る前に止めた場合。直前に右へ4回転以上回していれば、右3回でも開く
- 左始動の結果は、上の節の「番号列は右始動前提で設計」と同じ。押す側が逆になり、ツクの厚みのぶんゲートがずれる
- 手順ガイドは取扱説明書の手順をなぞって回数を数えるだけで、開くかどうかの判定には関わらない
- 表の値は、テスト（`test/model.test.js`・`test/readme.test.js`）が計算し直して確かめている

## 🎯 ユースケース

- 授業・研修: 物理セキュリティや機械の仕組みの授業で、手順の回数が「ディスクを1枚ずつ拾う」ことから来ていると、模型の動きで示す
- 金庫の持ち主: 自分の金庫の取扱説明書にある手順の意味を知り、回し過ぎたら最初からやり直す理由を確かめる
- 鍵・錠前の講習: 正規の操作の範囲で、固定ダイヤル錠の構造（ゲート・ツク・フェンス）を説明する補助にする
- 防犯の啓発: 固定ダイヤル錠が「もっともシンプルな構造で、それほど高い安全性は持たない」ことを、構造の理解とあわせて伝える
- 謎解き・脱出ゲームの制作: ダイヤル錠のギミックの説明や、番号と回す向きの考証に使う
- 展示・解説: 博物館や企業の展示で、実物の錠前の内部の動きを補う
- 小説・脚本の考証: 登場人物が正しい番号で金庫を開ける場面の手順と所作を確かめる
- プログラミング・機械設計の学習: 遊び（バックラッシュ）の連鎖の模型、決まった種での検算、SVGで描く画面を小さなコードで読む

本ツールは正規の操作を学ぶためのもので、他人の金庫を開ける用途は想定していません。悪用はおやめください。

## 🔒 セキュリティとプライバシー

- 操作の内容はブラウザーの中だけで処理し、外部へ送信しません
- Content Security Policy（meta）で、スクリプト・スタイルを同じ場所のファイルだけに限り、インラインのスクリプト・スタイルを許していません。外部への通信も許していません

- キー操作は、ダイヤルにフォーカスがあるときだけ受け付けます（ページ全体のキーを奪いません）
- 外部リンクには`rel="noopener noreferrer"`を付け、リファラーを送りません

## ⚠️ 注意と限界

- 教育用の簡略化した模型です。ツクの厚み（4目盛り）・許容幅（±1目盛り）は本ツールの値で、実機の寸法・許容幅・番号の制約はメーカーや機種で異なります。摩擦やバネの力は扱いません
- 正解番号94-30-84-13は、本ツール用の架空の番号です
- 対象は右始動の4枚座の固定ダイヤル錠です。可変変換型・電子錠・左始動の型は扱いません
- 破りの手法（ダイヤルの手応えから番号を探る方法など）は扱いません
- 自動実演③は「左に回して止めた状態」から始めた例です。初期状態によっては、右3回でも開きます
